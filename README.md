# Runway · Two Clinton Park

Valet OS demo for Two Clinton Park / 50 Clinton Place, New Rochelle.

- Resident app — request, schedule, cancel, live wait
- Valet console — clock in, take it out, finish
- Manager — coverage, map, restack, SLA
- Garage plate — `/garage-map.html` digitized from Lessard A-101 (3B), A-131 (3B slab), A-132 (2B slab). L-plate, two-way aisles, vehicle elevator at east wing. HOT / WARM / COLD / STACK / ADA. AM wave is drive-to-work / city / school — not Metro-North.

Protected evaluation access: enter email → one-time code → accept current Runway Evaluation Terms → Runway. See `EVAL_ACCESS.md`.

```
npm install
npm run dev
```

Vercel: build command `npm run build`.
Static map is served from `public/garage-map.html`.
